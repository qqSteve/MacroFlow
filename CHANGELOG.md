# Changelog

## 0.3.1 — UI Redesign

- Rebuilt desktop shell with no system titlebar and Windows resize handlers.
- Added consistent vector icons and interactive button visual states.
- Restyled all five views and introduced recording / tools navigation pages.
- Added list/compact step cards, action context menu, delay presets, updated inspector.
- Added working undo/redo for saved scenario edits, with bounded local history.
- Introduced expandable log with timestamps, unified transport controls.
- Kept the existing scenario data format, Recorder, Runner and GitHub updater integration.
- Expanded Qt smoke tests for all screens, selectors, and edit interactions.

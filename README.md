# MacroFlow — Automation Studio

> **Стартовый прототип v0.1.0**, а не готовый продукт для массового изменения документов в 1С. Перед использованием на рабочих данных необходимо протестировать каждый сценарий на копии.

MacroFlow — конструктор действий для Windows в графитовом оформлении с оранжевыми акцентами `#FF8B2B`, едиными для главной страницы, редактора и настроек.

## Что уже есть в исходном коде

- Единый стиль интерфейса PySide6 для всех трёх экранов.
- Создание и сохранение сценариев в `%APPDATA%\MacroFlow\scenarios.json`.
- Создание, удаление, копирование и перемещение шагов (стрелками и перетаскиванием).
- Общая задержка и индивидуальная задержка **после каждого действия** в миллисекундах (0–120 000 мс); значения складываются.
- Выделение области экрана и клик по её центру (абсолютные координаты).
- Простой исполнитель: клик, двойной клик, ввод **ASCII-текста**, клавиши, ожидание.
- Рекордер по `F7`: клики мыши и отдельные служебные клавиши. **Обычный вводимый текст не записывается из соображений приватности.**
- Глобальные горячие клавиши `F6` (старт/пауза), `F7` (запись), `F8` (остановить), `F9` (один шаг).
- Проверка GitHub Releases при запуске и по кнопке (в отсутствие релизов сообщает об ошибке без блокировки работы).
- GitHub Actions: сборка EXE, установщика Inno Setup и публикация в GitHub Releases по тегу `v*`.

## Пока НЕ реализовано

- Поиск текста или контрагента в 1С, OCR, UI Automation, проверка результата операций.
- Надёжный рекордер со сборкой введённых строк и интеллектуальными селекторами.
- Вставка русского текста исполнителем; это отдельная задача на буфер обмена / Windows UI Automation.
- Умные ожидания загрузки окон, циклы и условия, безопасный перезапуск с продолжением.
- Автоматическая **установка** обновления внутри приложения. **Проверка версий работает**, а скачивание/установка пока через страницу GitHub Releases.
- Изменение глобальных клавиш, иконка приложения, цифровая подпись и откат установки.

## Запуск из исходников (Windows 10/11)

Установите Python 3.12 (x64), затем в PowerShell:

```powershell
cd MacroFlow
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Глобальные перехватчики Windows могут требовать соответствующих разрешений. Во время записи не вводите секретные данные. Запись событий происходит только после запуска с `F7`.

## Структура

- `macroflow/app.py` — интерфейс и редактор.
- `macroflow/theme.py` — единая тема.
- `macroflow/store.py` — локальное сохранение сценариев.
- `macroflow/recorder.py` — глобальные горячие клавиши и запись событий.
- `macroflow/engine.py` — выполнение шагов с остановкой и паузой.
- `macroflow/overlay.py` — выделение области.
- `macroflow/updates.py` — проверка GitHub Releases.
- `.github/workflows/windows-release.yml` — автоматическая сборка и релиз.
- `installer/macroflow.iss` — установщик Inno Setup.

## GitHub и релизы

1. Создайте в GitHub пустой репозиторий `MacroFlow` (публичный, если хотите скачивать обновления без авторизации).
2. Загрузите в него содержимое папки **MacroFlow-starter**. Если владелец репозитория не `qqSteve`, исправьте `GITHUB_REPOSITORY` в `macroflow/__init__.py`.
3. До создания первого релиза убедитесь, что версия в `macroflow/__init__.py` соответствует тегу.
4. Создайте и отправьте тег (пример для первой версии):

   ```powershell
   git tag v0.1.0
   git push origin v0.1.0
   ```

5. В GitHub Actions запустится Windows-сборка. После завершения в Releases появится `MacroFlow-Setup-0.1.0.exe` и `.sha256`.

**Важно:** сейчас `updates.py` умеет только определять наличие релиза и открывать его страницу. Для безопасной автоустановки потребуется отдельный обновлятор, проверка подписи или хеша и защита пользовательских файлов. Сам Github Actions workflow требует проверки на реальном GitHub runner — пока сборка не запускалась.

## Безопасность

- Пользователь инициирует запуск сценария явно; автоматически действия не выполняются.
- Исполнитель работает с текущим рабочим столом: перед стартом убедитесь, что открыта нужная программа и нужный документ.
- В `pyautogui` включён аварийный останов при перемещении курсора в угол экрана (`FAILSAFE`).
- `F8` запрашивает остановку, но уже начатое действие может закончиться прежде, чем остановка сработает.
- Перед массовым проведением документов обязательно проверяйте операции вручную на тестовой базе.

# Обновление MacroFlow 0.1.0 → 0.2.0 (Windows)

**Не удаляйте старую папку и `.git`**: в ней уже есть привязка к вашему GitHub.

1. Для страховки закройте MacroFlow и скопируйте `%APPDATA%\MacroFlow\scenarios.json` в любое безопасное место.
2. Распакуйте `MacroFlow-v0.2.0-update.zip` **в корень того же проекта**, где сейчас находятся `main.py`, `macroflow/`, `.github/`, `.git/`. Согласитесь заменить старые файлы. Архив не содержит `.git` и не удалит ваши сохранённые сценарии.
3. В том же PowerShell, где ранее выполняли `git push`, проверьте изменённые файлы:

   ```powershell
   git status
   git add .
   git commit -m "MacroFlow v0.2.0: repeats, imports, refreshed UI"
   git push origin main
   git tag v0.2.0
   git push origin v0.2.0
   ```

4. Проверьте https://github.com/qqSteve/MacroFlow/actions и дождитесь **успешной** сборки; установщик появится по адресу https://github.com/qqSteve/MacroFlow/releases.
5. Установите новую версию поверх предыдущей. Сценарии хранятся отдельно от программы в `%APPDATA%\MacroFlow`.

Если `git status` показывает, что файлы не изменились, скорее всего архив распакован во вложенную папку. Проверьте путь и перенесите **содержимое** архива в корень рабочего репозитория.

Не используйте `git push --force`, не удаляйте старый тег `v0.1.0` и не удаляйте `%APPDATA%\MacroFlow`.

## Оговорки

Инсталлятор Windows собирается только на GitHub Actions; сам архив — **исходный код**, а не готовая Windows-программа. Дополнительные тесты интерфейса и записи действий стоит выполнить на вашем компьютере перед автоматизацией рабочих документов 1С.
